## 一、合规红线（先读这条）

飞书原文在饮食表上方写着：

> 注意⚠️容易被平台误判成养生医疗，可以讲文化，但不要讲成"吃什么治什么"。
> 《黄帝内经》里有"五谷为养，五果为助，五畜为益，五菜为充"的饮食原则，核心是均衡、不过量、顺应四时，而不是单一食物治病。

**主播提示词（原文）**：

> 五音、五行、五志、五脏，是东方传统文化里理解声音、身体、情绪和自然节律的一套象征系统。我们不是说听一首音乐就能治病，而是借这套系统，帮助大家更细腻地感受自己的情绪、呼吸、身体状态和内在节奏。

落到产品上的三条硬约束：

1. **讲文化，不讲疗效。** 面向用户的文案一律走「音乐气质 / 情绪转化方向 / 适合直播讲法」
   这三行的口径，不用「疏肝理气」「柔肝宁神」「调理脏腑」这类中医治疗动宾结构。
2. **脏腑、五味、五谷等只作为文化对照展示，不与"改善/治疗"连用。** 表里的
   `五脏 / 五腑 / 五官 / 五体 / 五华 / 五液` 属于文化知识层，可以标注，不可以承诺。
3. **饮食维度只保留"可讲"一列**（见下文饮食表），"不建议讲"一列永远不进产品文案。

## 五、与代码的对应关系

### 5.1 字段映射

`Element` 的一级列只放渲染主链路要用的东西，其余 30 多个维度统一塞进
`element.meta`（JSON 列，后台可编辑；前端 `WuxingElement.meta`）。
**不要为每个维度加一列** —— 这些维度只做展示与文案取材，加列会把
`ElementIn` / `Elements.vue` 表单撑成三十多个输入框。

| 本文档行 | 落到哪里 |
| --- | --- |
| 五音，音乐 | `element.note` |
| 季节 | `element.season` |
| 五脏 + 五腑 | `element.organ`（合写，如「肝胆」；拆开的单值在 `meta.organZang` / `meta.organFu`） |
| 基本气质 | `element.quality`（取第一个词，如「生发」；完整三词在 `meta.temperament`） |
| 音乐气质 | `element.desc`（面向用户的一句话描述） |
| 适合直播讲法 | `element.sleep_tip`（result / element 页的「Healing Direction」文案） |
| 情绪失衡表现 | `meta.imbalance` —— 测评题干取材 |
| 情绪转化方向 | `meta.transform` —— result 页展示 |
| 其余 30 行 | `meta.*`，见下表 |

### 5.3 五色 ≠ UI 主色（有意为之）

传统五色是 `青 / 赤 / 黄 / 白 / 黑`，但本产品是**深色冥想底**（`$bg-deep: #03050a`），
「水 = 黑 / 玄」作主色在黑底上不可见，「火 = 正赤」在深色底上对比过硬。
所以 UI 主色保持现有一套（见 `src/styles/variables.scss` 的 `$wuxing-colors`），
**五色只作为文化字段存在 `meta.colorName`**，用于文案与知识展示。

| 元素 | UI 主色（实际渲染） | 传统五色（`meta.colorName`） |
| --- | --- | --- |
| 木 | `#84cc16` 黄绿 | 青 / 绿 |
| 火 | `#f97316` 橙 | 赤 / 红 |
| 土 | `#eab308` 黄 | 黄 ✅ 一致 |
| 金 | `#cbd5e1` 银白 | 白 ✅ 一致 |
| 水 | `#38bdf8` 天蓝 | 黑 / 玄 |

改配色前先看这一节——不是漏了，是权衡过的。

### 5.4 频率（174/396/528/741Hz）不在本文档里

`track.hz` 上的 174 / 396 / 528 / 741Hz 来自现代频率疗法，**飞书文档没有这套对应**，
它是产品自己叠加的一层。两套体系并行没问题，但文案上别把它说成"古法"，
也别宣称频率有生理疗效。
