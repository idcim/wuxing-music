# 管理后台业务页与 Vben

## 来源与边界

使用 Vue Vben Admin 官方 v5.7.0（MIT），来源与重建方式见 [vendor/README.md](../admin/vendor/README.md)。
本次覆盖 `admin/src/views/` 的 24 个视图：16 个业务路由、设置中心内的 7 个面板和登录页。

- `BusinessPage` 使用官方 Page，统一标题、说明、内容区间距；列表页默认包含原生 Vben Card。
- `BusinessCard` 使用官方 shadcn Card。仪表盘、音频历史等自行组织卡片的页面设置 `:card="false"`。
- `BusinessModal` / `BusinessDrawer` 使用官方 `useVbenModal` / `useVbenDrawer`，兼容业务页的 `v-model` 和 footer 插槽。弹窗采用视口内滚动及固定操作栏。
- 表格、表单、分页使用 `BusinessTable` / `BusinessForm` / `BusinessPagination`，底层是 Element Plus。表格事件、选择和排序、表单验证继续使用原有接口。
- 输入、选择、上传、标签、确认框等沿用 Element Plus；`styles/business.css` 将颜色、边框和背景映射到 Vben 主题，页面不各自覆盖深浅色。

业务脚本、请求参数、服务端权限和校验保持原样。没有引入上游示例登录或示例业务接口。

## 通用工具恢复（2026-10-26）

早期迁移仅引入核心 workspace 并自行拼装业务壳层，曾显式设置 `enableCheckUpdates:false`，且没有挂载官方 effects/layouts 的通用工具，导致只剩布局而丢失部分后台体验。现保留上游核心源码，在业务适配层补齐以下实际接入：

| 功能 | 当前实现 |
| --- | --- |
| 自动检测更新 | 默认开启，沿用 Vben 的 `enableCheckUpdates` 和分钟间隔；对比当前已加载后台构建与同次构建生成的 `admin-version.json`，页面恢复可见时立即检查。检测到新版本用 Vben 弹窗提示，用户保存内容后自行刷新，不强制刷新。手动检查仍可用。 |
| 旧偏好迁移 | 只对旧迁移强制关闭的更新开关做一次性恢复；保留其他个人偏好，之后可在设置中自行关闭。 |
| 全屏 | 使用官方 `VbenFullScreen`。 |
| 菜单搜索 | 搜索实际业务菜单，经过同一权限与模块开关过滤，支持 Ctrl/Command+K；路由与服务端鉴权继续有效。 |
| 偏好设置 | Vben 抽屉维护主题／跟随系统、深色侧栏、侧栏宽度和悬停展开、标签栏、工具可见性、动态标题、自动更新及间隔；全部连接真实偏好，浏览器持久化。恢复默认不清理登录或业务数据。 |
| 标签与标题 | 标签栏提供刷新、关闭左侧／右侧／其他标签；文档标题跟随站点品牌与菜单。开启“保留标签页状态”后，按业务路径隔离缓存，切换菜单保留表单与筛选。关闭标签、刷新当前页、关闭缓存或切换账号会清理对应状态。 |

不把未接入的上游选项伪装成可用开关：多语言需要业务文案翻译，锁屏需要现有账号验证流程；上游标签拖拽、固定标签及全部布局模式仍未接入。当前偏好面板仅展示实际生效的选项。后续恢复应继续按业务适配进行，不再静默关闭通用能力。

页面缓存仅限当前账号可见的已打开业务标签，最多 16 个，不把未保存草稿写入浏览器存储；整页刷新后仍需重新编辑。曲目任务、音频历史、课件与交易任务列表在隐藏时停止轮询并忽略旧响应，返回时恢复。Vben 官方弹窗在页面停用时关闭。上传请求不因切换菜单取消，但关闭标签或整页刷新仍应等待上传完成。

更新清单属于后台前端自己的构建，不使用 API 的提交号判断前端是否更新；Nginx 对清单返回 `no-store`、HTML 返回 `no-cache`。开发模式不检查线上更新，生产包可在本地演练。自动检查隐藏时暂停，销毁时清理请求和定时器；临时网络错误保留后续重试。

## 后续页面约定

新增业务路由使用 `BusinessPage`，新增业务弹窗和抽屉使用统一组件。表单默认顶部标签；提示文字使用主题变量。
宽表允许在表格内部横向滚动；桌面固定操作列使用不透明背景，小屏取消固定以留出内容空间。
修改 `vendor/` 之前先判断是否可以在业务适配层完成，避免增加上游升级成本。

## 本地验收

构建命令：`cd admin && npm run build`（包含 vue-tsc）。
浏览器验收采用仅监听 localhost 的独立临时 SQLite/样例接口，不接共享数据库：

- 各业务菜单和设置分组可渲染，列表、空态、统计卡片及分页布局正常。
- 曲目编辑的 Vben 弹窗可打开、选择五行、取消并重新打开；用户重复账号抽屉可关闭。
- 深浅色下检查表格、表单、状态文字、弹窗、通知与设置面板。
- 390px 小屏检查筛选栏、表格内部滚动及长表单操作栏，页面无横向溢出。

这些检查验证前端布局与交互，不代表真实微信登录、支付、退款、OSS 上传和生产业务数据已完成端到端验收。

工具恢复验证：`node --test scripts/tests/admin-version-check.test.cjs` **6 项**通过；后台类型检查及生产构建通过，确认构建清单标识嵌入实际 JS。通过真实生产预览模拟发布另一个构建，浏览器自动出现“后台有新版本／稍后处理／刷新到新版”并检查截图；测试环境无真实渠道操作。其他新入口已在页面读取到，偏好／搜索／全屏的点击复核仍受浏览器控制超时限制。

标签缓存回归：`node --test scripts/tests/admin-route-cache.test.cjs` 使用真实 Vue 渲染器验证同名页面草稿隔离、切回保留、关闭销毁、仅刷新当前页、禁用缓存和账号切换清理；另验证首次激活不重复轮询、隐藏停止、旧微任务失效、恢复和卸载清理。该测试不替代浏览器中逐个业务表单的操作验收。
