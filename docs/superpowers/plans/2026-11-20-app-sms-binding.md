# APP 短信登录与微信绑定实施计划

**目标：** APP 复用现有短信服务登录，登录后可绑定微信，两种登录进入同一个账号。
**设计：** 短信登录和微信原生授权分离；短信配置沿用后台短信设置。绑定使用登录态及带用户、用途、应用标识的一次性挑战，微信身份冲突明确拒绝，不自动覆盖或转移财务数据。新增身份引用纳入版本化迁移、账号合并与注销。

- [x] 后端：公开短信就绪状态、微信绑定状态/挑战/确认、持久 APP 身份、迁移及账号生命周期检查。
- [x] APP：手机号/验证码登录、发送中与重发倒计时、协议默认不选、取消/退出不接收迟到登录结果；保留微信与游客入口。
- [x] 我的：微信绑定入口、绑定状态、主动授权及冲突提示。
- [x] 验证：独立数据库行为测试与迁移预演、前端登录/取消/绑定回归、类型检查、小程序/安卓构建、MuMu 本地响应替身 UI 验证；不发送真实短信、不创建生产账号。
- [x] 递增安卓体验包至 preview.5 / versionCode 2000005，记录验证范围，按既有授权提交推送 master。
