# 安卓启动图修复及正式签名包

目标：完整显示原始 LOGO，生成具有独立正式包名、长期发布签名、关闭调试能力的 release APK。沿用现有 Taro APP 功能，不自动开放尚未接入的原生支付或后台播放。

1. 冷启动录屏复现固定 dp 图层被系统缩放裁切；增加不同绘制边界的安全圆回归，静态图修复为比例缩进。用户后续要求拆解合成动画：沿原图提取火焰、内焰与弧线三个矢量部件，Android 12+ 用原生 AnimatedVectorDrawable 汇聚、亮起、短暂光轨和闪光，3 秒完成合成和收尾闪光，约 3.15 秒结束；旧安卓及关闭动画时静态回退。APP 直接进入下一业务页，不再串联旧月亮等待页。
2. 正式包使用 `cn.azureglow.wuxing`，体验包保持 `.preview`；两者的微信回调与更新渠道各自匹配，正式应用名称移除体验版标记。
3. 用户已授权新建长期签名。签名文件保存在仓库外，仅当前 Windows 用户可访问；密码用 Windows DPAPI 保存，不写入源码、参数或日志。构建缺签名时拒绝生成正式包。
4. 对齐 2.0.0 版本，生成 release APK、校验和及公开证书信息；验证非 debug、正确包名和证书、MuMu 冷启动及基础浏览。
5. 同步构建与运维文档，提交推送 master。APK 不自动上传 OSS 或发布下载渠道。

验证边界：正式签名与打包不是应用商店上架；更换正式包名与签名后，微信开放平台和后台 APP 管理需登记新公开标识。真实微信授权、短信、支付不在此次验证中。

执行结果：正式 APK 已生成、签名与身份校验通过，MuMu Android 15 安装/覆盖安装及原生冷启动录屏通过。用户要求放慢后改为约 3 秒，增强双向光轨、部件旋转及最终高光；系统关闭动画时回退通过，MuMu 动画缩放测试后恢复原值。93 项前端回归、类型检查、小程序构建和 1 项 Android 仪器测试（两种资源 × 三种绘制尺寸）通过。签名目录 ACL 已核对，仅当前用户与 SYSTEM，凭据未提交。实际交付摘要及 SHA256 见 ANDROID.md；APK 未上传 OSS。
