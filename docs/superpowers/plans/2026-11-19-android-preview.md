# 安卓体验版实施与验证

用户已确认先生成可安装体验版，用于检查现有页面、风格与播放器。继续维护小程序；不恢复 H5 产品更新。

## 交付设计

- 使用 Capacitor Android，APK 内置 Taro 的 Web 渲染产物，不加载远程 H5 首页。独立输出 `dist-android/`，应用标识 `cn.azureglow.wuxing.preview`，显示名称「五行律音体验版」。
- 复用现有 API、音频、品牌与风格 store。API 默认连接 `https://app.azure-glow.cn`，构建参数可覆盖。原小程序和 H5 的 API 行为保持原样。
- 安卓采用当前音乐、课程、商城、会员、我的导航；课程商城遵循后台展示开关。播放器默认收为按钮。硬件返回先回上一页，根页面返回桌面。
- 体验版保持游客态；登录页明确提示尚未开放账号登录，可以返回继续体验，不复用旧 H5 默认同意条款的登录流程，也不显示网页微信扫码入口。会员、礼物和课程商城购买在体验版关闭，不创建真实支付订单。独立安卓账号登录、支付、可靠锁屏播放不属于体验版验收。
- 图标来自用户提供的 `D:/Com/HCOM/青耀/appIcon/logo.jpg`，直接复用素材，不重新绘制。使用 Android 自适应图标与一致的启动背景。
- 本次生成 debug 签名体验 APK；不配置正式签名、不上传应用商店。源码提交，APK 放在忽略的 `artifacts/android/`。

## 实施顺序

1. 添加安卓构建标记和独立脚本、Capacitor 配置与 Android 工程。构建脚本检测 Java 21、SDK；产物复制为带版本名的 APK，附 SHA256。
2. 为安卓分支补齐导航、折叠播放器、前后台与硬件返回适配。禁用体验版购买与网页扫码登录；添加支付和配置回归用例，先确认用例失败再实现。
3. 从原 LOGO 配置启动图标，移除模板默认图标与启动插图。保持只申请网络权限。
4. 运行类型检查、小程序构建、安卓资源构建与 Gradle assembleDebug；执行支付和安卓边界测试。
5. 安装到本地安卓模拟器，通过实际画面和 WebView 调试检查启动、游客浏览、默认未勾选协议、音乐试听、播放器收展、返回及两种风格。风格切换用本地调试响应或 store 验证，不能擅自修改生产风格。
6. 记录安装路径、校验和、实际验证结果和未覆盖能力。按已有授权提交推送。
